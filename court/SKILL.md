# 朝政体系 Skill（court）
> 开源级别：**open（可开源）**——已同步至 dsh-skills 公开仓库
> ⚠️ **默认不安装（optional）**：本技能是「锦上添花」层——给 dsh 加一套**三省六部·君主视角**体验（君主手册 + 朝政看板模板）。
> 核心能力（对话 / 出图 / 交接 / 邮件 / QQ）都不依赖它；需要时手动复制本目录即可，不进入默认安装。

## 这是什么

一套源自真实实践的组织比喻 + 君主层产物模板，让用户对自家 dsh 系统「一眼看懂、一句话指挥」：

```
                ┌───────────────┐
                │ 皇帝（用户）    │  拍板 / 否决 / 授衔 / 改律
                └───────┬───────┘
   ┌────────────┬───────┴────────┬────────────┐
   │ 中书省·谋   │  门下省·审      │ 尚书省·行   │
   │ 管家大脑    │  guard 安全闸门 │ 桥+技能+系统 │
   └────────────┴────────────────┴─────┬──────┘
   ┌──────┐┌──────┐┌──────┐┌──────┐┌──────┐┌──────┐
   │ 吏部  ││ 户部  ││ 礼部  ││ 兵部  ││ 刑部  ││ 工部  │
   │人事凭据││仓储资源││典章文教││防务安全││律令审计││营造生产│
   └──────┘└──────┘└──────┘└──────┘└──────┘└──────┘
   ┌────────────────┐  ┌────────────────┐
   │ 御史台·监察     │  │ 内侍省·通传     │
   │ 巡检告警        │  │ 朝报 / 看板     │
   └────────────────┘  └────────────────┘
```

- **桥 = 尚书省的心脏**（地位最核心）：一切对话与工具调用都经它中转，桥挂 = 全部能力瘫痪；
  桥的改进开发 = 改中枢，按四步走（备份 → 语法检查 → 重启 → 冒烟验证），由尚书省直辖、高于六部。
- **君主层优先**：给用户看的产物（手册 / 看板）是体验核心，维护优先级最高。

## 内容

| 文件 | 用途 |
|---|---|
| `君主手册-模板.html` | 给用户看的「系统全局说明书」网页版：一句话规则 / 朝堂总览图 / 六部衙门表 / 指挥口令表 / 关键速查 / 日常自救 / 规矩。单文件自包含、响应式（手机可看）、锚点导航 |
| `君主手册-模板.md` | 同上内容的 md 源文档（html 为主看，md 作源与管家用，双格式同步） |
| `朝政看板-模板.html` | 单文件看板页：桥/ComfyUI 状态、磁盘、待决事项、最近动态、最近报告，30 秒自动轮询 `/system/board` |

## 安装（默认不安装，按需手动）

```powershell
# 1) 复制本目录到 dsh 工作区
Copy-Item court "<dsh>\skills\court" -Recurse

# 2) 手册模板：把 {{HANDBOOK_DIR}} / {{DOWNLOAD_DIR}} / {{VAULT_FILE}} / {{授权口令}}
#    替换为实际路径与口令（占位符见各文件内注释）

# 3) 看板模板：桥需要提供数据端点 GET /system/board
#    （JSON：bridge / comfyui / disk / pending / recent / reports / progress）
#    可参考 dsh-openai-bridge 的 dashboardHtml() 实现；部署后桌面建快捷方式打开即可
```

## 数据端点约定（GET /system/board）

```json
{
  "time": "ISO时间", "bridge": "ok", "comfyui": "up|down",
  "disk": [{"drive": "C", "freeGB": 30.2, "totalGB": 214.1}],
  "pending": ["- 👑 待拍板事项"], "recent": [{"ts": "MM-DD HH:mm", "task": "最近动态"}],
  "reports": [{"task": "任务", "file": "报告文件", "time": "yyyy-MM-dd HH:mm"}],
  "progress": {"active": false}
}
```

## 维护约定

- 手册双格式同步：改 md 后同步 html（或反之），随交接日志记录更新
- 开源版一律脱敏：本机路径用 `{{占位符}}`，口令/凭据位置不出现真实值
- 本技能与 `handover`（交接维护）互补：handover 管 AI 层档案，court 管君主层体验

## 铁律

1. 不写密钥、不写真实账号/口令、不写本机私有路径（占位符代替）
2. 改模板前先备份；看板模板改动需与桥的 `/system/board` 契约一致
3. 君主手册是"给用户看"的文档：措辞说人话、不堆 AI 内部术语
