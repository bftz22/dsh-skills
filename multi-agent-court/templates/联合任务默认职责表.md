# 联合任务默认职责表（通用模板 · 2026-08-20 宿主确立）

> 联合任务启用时的**默认分工依据**；宿主指令优先（「这个给 X」立即生效）。
> 与《三省六部职责划分.md》配套：部门级管政务归属，本表管任务模块分工。

## 默认职责（按任务类型）

| 任务类型 | 默认分工 | 说明 |
|---|---|---|
| 代码 / 开发 / 技术研究 | **技术大臣**主责；政务大臣规划/验收；内容大臣可测 | 工部·营造 |
| 美术 / 设计 / 内容创作 | **内容大臣**主责 | 工部·营造 |
| 文档 / 方案 / 数据汇总 / 运维 | **政务大臣**主责 | 中书省·谋 + 礼部 |
| 复合项目（游戏/软件） | 政务大臣=需求/数值/文档；技术大臣=代码；内容大臣=美术/内容 | 三臣齐上 |
| 出图 / 素材生产 | **一次一臣**（看板排队） | ComfyUI 共享 |
| 数据分析 / 评测 | 技术大臣跑数据；内容大臣解读；政务大臣汇总 | 数据链路 |
| 系统运维 / 安全检查 | **政务大臣**（不外包） | 兵部·防务 |
| 研究 / 情报收集 | 三臣各自搜索，政务大臣汇总 | 中书省·谋 |

## 通用规则（默认）

1. **规划与最终汇总归政务大臣**（除非宿主指定整合大臣）
2. **出图一次一臣**、**共享资源看板登记**（防冲突铁律）
3. 产出放宿主指定目录，分目录隔离（`<任务>\<大臣名>-<模块>\`）
4. 各臣完成后：看板 ✅ + 成果路径 + 自己档案留痕
5. 交接经宿主指令 → 移交书

## 流程改进机制（宿主掌舵）

- **宿主**随时说「**流程改进：<建议>**」→ 政务大臣立即更新本表 + 各大臣 SKILL.md，并登记《流程改进记录.md》
- **三臣**任务完成后可提改进建议（奏章/看板「流程反馈」）→ 政务大臣汇总 → 宿主拍板 → 更新
- 流程是活的：默认职责是起点，宿主说改就改
