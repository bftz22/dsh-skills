# 联合任务 Skill（多智能体协办 · 开源通用版）

> 触发：宿主说「**联合任务：<任务>**」或「**多智能体协办：<任务>**」——即启用联合任务模式。
> 本技能是**政务大臣**侧的联合任务守则；技术大臣/内容大臣各持同版（视角相同）。
> 本文件为开源通用模板：原体系中的本机路径、端口、称呼均已替换为占位符，接入时请按 README 说明替换。

## 一、启用流程（收到指令后）

1. 读本技能（本节）与 `<COURT_DIR>/三省六部职责划分.md`（分工依据）
2. 读 `<COURT_DIR>/公务看板.md`——登记本臣任务（状态 🔄 进行中）
3. 读 `<COURT_DIR>/移交书存档/`——有无移交书需接
4. 读自己档案（章程/交接日志/任务清单）——知前情

## 二、分工规则

- 默认按职责划分：政务归政务大臣、工部代码归技术大臣、美术/内容归内容大臣、出图一次一臣（看板排队）
- **宿主指令优先**：「政务大臣做 X，技术大臣做 Y，内容大臣做 Z」= 并行；「X 交给 Y」= 移交书流转
- 共享资源（ComfyUI/NapCat/IDM）用前登记看板「共享资源状态」

## 三、执行纪律

- 各臣只做**宿主分派的模块**，产出放宿主指定目录（分目录：`<任务目录>\<大臣名>-<模块>\`）
- **不读对方档案、不代传命令、不碰凭据、不冒充宿主**（隔离铁律不变）
- 进程归属铁律：<PORT_MAIN> 政务大臣 / <PORT_TECH> 技术大臣 / <PORT_CONTENT> 内容大臣 / 共享服务登记后使用

## 四、汇聚与交接

- 办结 → 公务看板更新 ✅ + 成果路径；写自己档案（交接日志/政事日志）
- 需要整合 → 宿主指定整合大臣（经授权读取各模块产出）
- 移交 → 按 `<COURT_DIR>/移交书-模板.md` 写移交书

## 五、汇报

- 各臣完成后奏报宿主（政务大臣=对话汇报 + 交接日志；技术/内容大臣=奏章）
- 宿主说「两边报进度」→ 各自汇报由宿主汇总

## 附：启用检查（政务大臣执行）

收到启用指令时，先跑：
```powershell
powershell -File <SKILLS_DIR>/joint-task/joint-task-check.ps1
```
（检查三桥状态 + 看板摘要，向宿主呈报后开工）

## 默认职责（2026-08-20 宿主定）
- 按任务类型分工见 **<COURT_DIR>/联合任务默认职责表.md**（代码→技术大臣、美术内容→内容大臣、文档规划汇总→政务大臣、出图一次一臣）
- 宿主指令优先；共享资源看板排队

## 流程改进（宿主掌舵）
- 宿主说「流程改进：<建议>」→ 政务大臣更新职责表与各大臣 SKILL.md，登记 <COURT_DIR>/流程改进记录.md
- 各臣任务后可提改进建议（奏章/看板）→ 宿主拍板 → 执行
