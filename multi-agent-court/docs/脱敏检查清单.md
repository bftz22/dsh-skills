## 二、敏感词类别（扫描关键词，按类别描述）

1. **路径类**：通传区根路径、用户主目录、下载目录、ComfyUI 根、凭据目录（均以类别描述指代，不写原文）
2. **称呼类**：原三臣称呼、原君主称呼（均以类别描述指代）
3. **端口类**：三臣与共享服务端口（原端口号已全部占位化，此处不列举）
4. **账号类**：QQ 号、个人邮箱（开源包内不得出现原文）
5. **凭据类**：API 令牌、密码（开源包内不得出现原文）
6. **工程痕迹类**：本机桥接工程名、内部项目名、具体任务实例（以类别描述指代）
7. **原体系技能痕迹类**：本机技能目录路径与 private 技能名（原 private 技能一律不提名称）

> 说明：真实账号/凭据/用户名的**原文仅存在于本机原检查脚本与源文件**，本开源包（含本清单）一律以类别或占位符指代。

## 三、检查方法

```powershell
# 发布前对开源包目录执行扫描（示例：用类别关键词，勿在脚本中写真实账号）
$dir = '<开源包路径>\multi-agent-court'
$kws = @('<盘符>:\','C:\Users\','@','harness','bridge')
Get-ChildItem $dir -Recurse -File | ForEach-Object {
  $c = Get-Content $_.FullName -Raw -Encoding UTF8
  foreach ($kw in $kws) {
    if ($c -match [regex]::Escape($kw)) { Write-Host "!! $($_.FullName) 含 [$kw]" }
  }
}
# 另查：真实 QQ 号、个人邮箱、令牌原文（仅本机执行，命中即禁止发布）
# 零命中 = 通过；有命中 = 禁止发布
```

> 另可复用本机原体系的 `check-skill-license.ps1` 检查思路（SKILL.md 开源级别标记 + 凭据/路径扫描，凭据清单在本机原脚本中维护，不随包发布）。
