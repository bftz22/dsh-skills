# multi-agent-court · 多智能体协作框架（开源通用模板）

> 一套「多智能体联合任务协作」的开源模板：三臣分工体系 + 通传文书 + 调度链路约定。
> 源自个人 AI 管家体系的实战沉淀（2026-08-20 宿主确立），已**全面脱敏**：本机路径、端口、账号、称呼均替换为占位符。

## 角色映射

| 本模板角色 | 职责 |
|---|---|
| 政务大臣 | 文档 / 方案 / 数据汇总 / 运维 / 规划与最终汇总 |
| 技术大臣 | 代码 / 开发 / 技术研究 / 数据分析执行 |
| 内容大臣 | 美术 / 设计 / 内容创作 / 解读评测 |
| 宿主 | 任务发布 / 分工授权 / 流程拍板 |

## 接入步骤

1. 通读 `docs/脱敏检查清单.md`，按对照表把占位符替换为你的环境：
   - `<COURT_DIR>` → 你的通传区目录（如 `D:\my-court`）
   - `<PORT_MAIN>` / `<PORT_TECH>` / `<PORT_CONTENT>` → 三臣服务端口
   - `<USER_HOME>` / `<QQ_ID>` → 你的主目录与消息账号
2. 将 `templates/` 四个文书放入你的通传区目录
3. 将 `skills/joint-task/` 部署到你的技能目录（`<SKILLS_DIR>/joint-task/`）
4. 各智能体按 SKILL.md 的启用流程开始协作

## 协作要点（骨架）

- **派活**：宿主说「政务大臣做 X，技术大臣做 Y」＝并行授权；「X 交给 Y」＝移交书流转
- **执行**：各臣只做分派模块，产出分目录隔离；不读对方档案、不碰凭据
- **交接**：办结 → 公务看板 ✅ + 成果路径；移交 → 移交书入存档，接收方回执
- **共享资源**：出图/下载等一次一臣，看板「共享资源状态」用前查、用后清

## 安全约定

- 隔离铁律：各智能体档案互不读写，只经通传区互通（除非宿主明确命令）
- 密钥纪律：密钥/令牌/密码绝不写入任何文档、日志、回复
- 进程铁律：禁止强杀宿主体系核心进程；起服务前先查端口
- 发布前必跑脱敏检查（见 docs/脱敏检查清单.md）
