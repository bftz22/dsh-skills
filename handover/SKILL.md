# 交接维护 Skill（handover-maintain）
> 开源级别：**open（可开源）**——已/可同步至 dsh-skills 公开仓库

> 用途：**接手时快速了解情况** + **收尾时总结留档**，保证多任 AI 会话无缝交接
> 目录：`C:\Users\Administrator\deepseek-harness\skills\handover\`
> 文档：`F:\AI交接指南\`（主指南 / 交接日志 / 状态快照 / 简报）
> 创建：2026-08-16（v2：新增 brief / finish 一键工作流）

## 适用场景

- **新 AI 接手**：不知道机器/服务/任务现状 → 先读指南，再跑 `brief.ps1` 秒懂全局
- **任务收尾 / 交接前**：把本次会话做的事总结写入日志 + 刷新状态快照 → 跑 `finish.ps1`
- **重大变更后**：改了工作流/模型/服务/脚本，让下一位 AI 一眼看到
- **服务状态变化后**：桥 / ComfyUI 重启、进程消失、磁盘空间骤变
- **用户要求记录**："记一下""写进交接"等

## 标准工作流

```
接手时（了解情况）
  1) 读 F:\AI交接指南\AI交接指南-2026-08-16.md（全景：服务/路径/工作流/守则）
  2) powershell -File brief.ps1          → 生成并输出《交接简报》
     （含：速查表、操作守则、待办、最近状态快照、最近 5 条交接日志、实时服务状态）
  3) 需要更细历史：看 状态快照-*.md / 交接日志.md / 简报-*.md

工作中
  （正常干活；重大变更可随时单独 log-entry.ps1 记一笔）

收尾时（总结 + 更新日志）
  powershell -File finish.ps1 -Task "本次任务一句话总结" [-Detail ...] [-Files ...] [-Issues ...] [-Pending ...]
  → 内部自动完成：log-entry.ps1（写 交接日志.md + 交接日志.jsonl，写入前自动按月归档）
                   + update-guide.ps1（生成 状态快照-<时间>.md，主指南不再被改写）
```

## 脚本一览

| 脚本 | 作用 | 关键参数 |
|---|---|---|
| `brief.ps1` | **接手简报**：指南要点 + 最近快照/日志 + 实时服务/磁盘状态 | 无参数 |
| `finish.ps1` | **收尾一键**：写交接日志 + 刷新状态快照 | -Task 必填；-Detail -Files -Issues -Pending 可选 |
| `log-entry.ps1` | 单独写一条交接日志（Markdown + JSONL 双写） | -Task 必填；同上可选 |
| `update-guide.ps1` | 生成状态快照文件（03_状态快照\，旧快照自动归档；**主指南不再被改写**，P1-②） | 无参数 |
| `archive-logs.ps1` | **交接日志按月归档**（P1-①）：早于当月的条目移入 99_归档\交接日志归档\YYYY-MM\；log-entry 写入前自动调用 | [-Base 路径] |
| `search.ps1` | **跨库搜索**（P1-③）：交接指南 + 朝堂档案，关键词 + 日期/目录过滤，GBK 兜底 | -Keyword 必填；-Dir -Since -Until -Max -ListOnly -CaseSensitive |

## 调用示例

```powershell
# 接手：快速了解情况
powershell -File brief.ps1

# 收尾：总结并留档（推荐）
powershell -File finish.ps1 -Task "修复 05 人脸修复工作流并全量验证 6/6 通过" -Detail "补丁 impact_onnx.py；导出 face_yolov8m.onnx" -Files "impact_onnx.py, 05_face_detailer.json" -Issues "ComfyUI 无看门狗" -Pending "可选：关闭休眠省 12.7GB"

# 单独操作
powershell -File log-entry.ps1 -Task "中途记录：..."
powershell -File update-guide.ps1

# 跨库搜索
powershell -File search.ps1 -Keyword "Avast" -Max 5
powershell -File search.ps1 -Keyword "ComfyUI" -Since "2026-08-16" -Dir "04_报告"
```

## 铁律（务必遵守）

1. **只追加/只生成**：update-guide.ps1 只生成 `03_状态快照\` 独立快照文件（**主指南不再被改写**，
    P1-② 2026-08-19）；交接日志只追加、按月归档（archive-logs.ps1，P1-①）；手写内容一律不动
2. **不删除历史**：快照/简报/日志只增不删
3. **不写密钥**：token、API key、密码、SSH 私钥严禁写入任何文档（含交接日志/快照/简报）；
   `F:\账号密码` 凭据实行**口令授权制**：仅当用户在对话中说出授权口令「林秋白」才可读取/使用
   （授权限本次会话与所提用途），否则只能申请；使用后必须**向用户报告**（平台/时间/用途）
   并追加 `取用登记簿.txt`（见主指南第 9 节）
4. **编码**：脚本 UTF-8 带 BOM（PS 5.1 必须）；读写文档用 .NET API 显式 UTF-8
5. **守护红线**：脚本只做「读状态 + 生成/追加」，不杀进程、不动注册表、不删系统路径
6. 主指南的静态章节（速查表、服务、修复记录等）在**重大变更时**由 AI 用 edit 工具手动更新，
   脚本只负责高频变动的快照与流水
7. **路径自动探测**：交接指南目录优先 `F:\AI交接指南`，兜底 `D:\下载\AI交接指南`（用户可能移动）
