# 交接维护 Skill（handover-maintain）

> 用途：**接手时快速了解情况** + **收尾时总结留档**，保证多任 AI 会话无缝交接
> 创建：2026-08-16（v2：新增 brief / finish 一键工作流）

## 适用场景

- **新 AI 接手**：不知道机器/服务/任务现状 → 先读指南，再跑 `brief.ps1` 秒懂全局
- **任务收尾 / 交接前**：把本次会话做的事总结写入日志 + 刷新状态快照 → 跑 `finish.ps1`
- **重大变更后**：改了工作流/模型/服务/脚本，让下一位 AI 一眼看到
- **服务状态变化后**：服务重启、进程消失、磁盘空间骤变
- **用户要求记录**："记一下""写进交接"等

## 目录结构约定（交接指南目录）

```
<HANDOVER_DIR>\                     ← 用环境变量 HANDOVER_DIR 指定，默认 D:\AI交接指南
├── 00_主指南\AI交接指南-<日期>.md  ← 主文档（机器全景/服务/守则/修复记录/状态快照）
├── 01_交接日志\
│   ├── 交接日志.md                 ← 人读：每次任务的记录流水
│   └── 交接日志.jsonl              ← 机读：每行一条 JSON（时间/会话/任务/详情/变更/问题/待办）
├── 02_简报\
│   └── 简报-YYYYMMDD-HHMM.md       ← brief.ps1 每次运行生成一份（接手用）
├── 03_状态快照\
│   └── 状态快照-YYYYMMDD-HHMM.md   ← update-guide.ps1 每次运行生成一份
└── 04_报告\
    └── <任务名>报告\               ← 各任务报告按任务名分子文件夹存放
```

> 脚本自动探测：`HANDOVER_DIR` 环境变量优先，其次 `D:\AI交接指南`、`C:\AI交接指南`；兼容新旧子文件夹布局。

## 标准工作流

```
接手时（了解情况）
  1) 读 <HANDOVER_DIR>\00_主指南\AI交接指南-<日期>.md（全景：服务/路径/工作流/守则）
  2) powershell -File brief.ps1          → 生成并输出《交接简报》
     （含：速查表、操作守则、待办、最近状态快照、最近 5 条交接日志、实时服务状态）
  3) 需要更细历史：看 状态快照-*.md / 交接日志.md / 简报-*.md

工作中
  （正常干活；重大变更可随时单独 log-entry.ps1 记一笔）

收尾时（总结 + 更新日志）
  powershell -File finish.ps1 -Task "本次任务一句话总结" [-Detail ...] [-Files ...] [-Issues ...] [-Pending ...]
  → 内部自动完成：log-entry.ps1（写 交接日志.md + 交接日志.jsonl）
                   + update-guide.ps1（刷新指南状态快照段 + 生成 状态快照-<时间>.md）
```

## 脚本一览

| 脚本 | 作用 | 关键参数 |
|---|---|---|
| `brief.ps1` | **接手简报**：指南要点 + 最近快照/日志 + 实时服务/磁盘状态 | 无参数 |
| `finish.ps1` | **收尾一键**：写交接日志 + 刷新状态快照（内部调用下面两个） | -Task 必填；-Detail -Files -Issues -Pending 可选 |
| `log-entry.ps1` | 单独写一条交接日志（Markdown + JSONL 双写） | -Task 必填；同上可选 |
| `update-guide.ps1` | 单独刷新指南「状态快照」段 + 生成快照文件 | 无参数 |

## 调用示例

```powershell
# 接手：快速了解情况
powershell -File brief.ps1

# 收尾：总结并留档（推荐）
powershell -File finish.ps1 -Task "修复 XX 工作流并验证通过" -Detail "补丁说明" -Files "文件列表" -Issues "遗留问题" -Pending "待办"

# 单独操作
powershell -File log-entry.ps1 -Task "中途记录：..."
powershell -File update-guide.ps1
```

## 报告存放约定

**所有任务报告默认存 `<HANDOVER_DIR>\04_报告\`**（子文件夹按任务命名，如 `素材整理报告\`），
除非用户另有要求（如明确指定其他目录）。

## 铁律（务必遵守）

1. **只改标记区/只追加**：快照标记段（`<!-- SNAPSHOT:START -->`~`<!-- SNAPSHOT:END -->`）由脚本生成；
   日志只追加；手写内容一律不动
2. **不删除历史**：快照/简报/日志只增不删
3. **不写密钥**：token、API key、密码、SSH 私钥严禁写入任何文档（含交接日志/快照/简报）
4. **编码**：脚本 UTF-8 带 BOM（PS 5.1 必须）；读写文档用 .NET API 显式 UTF-8
5. **守护红线**：脚本只做「读状态 + 写标记区/追加」，不杀进程、不动注册表、不删系统路径
6. 主指南的静态章节（速查表、服务、修复记录等）在**重大变更时**由 AI 手动更新，
   脚本只负责高频变动的快照与流水
7. **路径自动探测**：交接指南目录优先 `HANDOVER_DIR` 环境变量，兜底 D:/C 盘常见位置（用户可能移动）
